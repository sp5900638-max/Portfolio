## 🛠️ Stack & Dependencies

- **Runtime & Bundler**: Vite 8.3
- **3D Graphics**: Three.js (WebGL, BufferGeometry, PointsMaterial, MeshStandardMaterial)
- **Icons**: Lucide Icons & optimized SVG
- **Audio**: Web Audio API (real-time zero-latency synthesized sound effects)
- **Typography**: Space Grotesk, Plus Jakarta Sans, Fira Code
